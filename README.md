# FluxEngine

FluxEngine is (hopefully) a 2D game engine project.


Build the solution with `dotnet build FluxEngine.slnx`.

Run the SDL window and WASD movement demo with:

```text
dotnet run --project demos/FluxEngine.Demo
```

Move the blue square with WASD and close the demo with Escape or the window close button.
SDL2 must be available on your system as `SDL2.dll`.
